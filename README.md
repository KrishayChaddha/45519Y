# Robot Rodeo Code (45519Y)

## Overview
This repository contains the official code used by **Team 45519Y** for the **Robot Rodeo competition**. It includes all robot control logic, autonomous routines, and driver control systems used during competition.

## Purpose
The goal of this codebase is to:
- Control the robot during matches
- Support autonomous and driver-controlled modes
- Provide a stable and reliable competition-ready system
- Allow easy updates and improvements throughout the season
